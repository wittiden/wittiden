## 🌟 About Me

I am a backend engineer focused on developing **scalable APIs**, **distributed systems**, and **production-ready backend applications**.

I enjoy designing systems that are:

- scalable
- maintainable
- fault tolerant
- observable
- easy to extend

My primary interests include backend architecture, asynchronous processing, distributed systems, testing, CI/CD, and observability.

---

## 🎯 Engineering Goal

Build reliable backend systems capable of handling millions of requests with high availability, efficient resource utilization, and comprehensive observability.
